## 오늘 배운 것

### 핵심 표현 (말투 표시)
- きのう 何(なに)を 食(た)べましたか。(키노- 나니오 타베마시타카) 어제 무엇을 먹었습니까? [정중체]
- きのう カフェで ケーキを 食(た)べました。(키노- 카페데 케-키오 타베마시타) 어제 카페에서 케이크를 먹었습니다. [정중체]
- きょう コーヒーを 飲(の)みませんでした。(쿄- 코-히-오 노미마셍데시타) 오늘 커피를 마시지 않았습니다. [정중체]
- すみません、トイレは どこですか。(스미마셍, 토이레와 도코데스카) 저기요, 화장실은 어디입니까? [정중체] / 더 공손하게: お手洗(てあら)い(오테아라이)
- すみません、水(みず) ありますか。(스미마셍, 미즈 아리마스카) 저기요, 물 있습니까? [정중체, 말할 땐 は 생략 자연스러움]
- はい、あります。/ 水は ありません。(하이, 아리마스 / 미즈와 아리마셍) 네, 있습니다. / 물은 없습니다. [정중체, 점원 대답]
- じゃあ、お茶(ちゃ) ありますか。(쟈-, 오챠 아리마스카) 그럼, 차 있습니까? [정중체]
- これ(は) いくらですか。(코레와 이쿠라데스카) 이거 얼마입니까? [정중체]
- すみません、パンと コーヒー ください。(스미마셍, 판토 코-히- 쿠다사이) 저기요, 빵하고 커피 주세요. [정중체]
- すみません、パンを ひとつ、コーヒーを ふたつ ください。(스미마셍, 판오 히토츠, 코-히-오 후타츠 쿠다사이) 빵 하나, 커피 두 개 주세요. [정중체] / 짧게: パン ひとつと コーヒー ふたつ ください。
- ビール ください。(비-루 쿠다사이) 맥주 주세요. [정중체]

### 문법 / 문장 구조
- 「〇〇は ありますか」 = 〇〇 있습니까? / 대답 あります(있습니다) · ありません(없습니다)
- 「〇〇と △△」 = 〇〇하고 △△ (명사 잇기)
- 개수: ひとつ(히토츠, 하나), ふたつ(후타츠, 둘). 순서는 [물건] + [개수] + ください (한국어와 같음)
- で vs では: で = 에서 / では = 에서는 (비교·대조 느낌). 그냥 말할 땐 で
- 동사 부정 과거는 〜ませんでした. 「〜ではありません / じゃないです」는 명사용 (学生じゃないです = 학생이 아닙니다)
- 말할 때 は/を 생략이 자연스러운 경우가 많음 (水 ありますか / 水 ください)
- 새 단어: じゃあ(쟈-, 그럼), これ(코레, 이것), いくら(이쿠라, 얼마), きょう(쿄-, 오늘), 何(なに, 나니, 무엇), 店員(てんいん, 텐인, 점원)

### 가타카나 읽기
- 동그라미(゜)는 "ㅍ": ハ→パ(파), フ→プ(푸) / 점 두 개(゛)는 "ㅂ": バ(바)
- ン = 받침 ㄴ/ㅇ ("운"처럼 따로 읽지 않음). ソ(소)·シ(시)와 모양 비슷
- ス(스) ≠ サ(사)
- 오늘 읽은 단어: スーパー(스-파-, 마트), タクシー(타쿠시-, 택시), ビール(비-루, 맥주), トイレ(토이레, 화장실), バス(바스, 버스), パン(판, 빵, 포르투갈어 유래), パスポート(파스포-토, 여권), スプーン(스푸-ㄴ, 숟가락)

### 새로 나온 한자
- 何(なに, 나니) 무엇
- 食(た)べます (타베마스) 먹다
- お茶(ちゃ, 오챠) 차
- お手洗(てあら)い (오테아라이) 화장실
- 店員(てんいん, 텐인) 점원
- 복습: 駅(えき)·水(みず)·飲(の)む 모두 한자로 읽음 ✅

## 약점 (다음 수업 복습 대상)
1. 가타카나 비슷한 글자: ス/サ (スーパー를 사-바-로), パ/バ (゜와 ゛), ン/ソ/シ (パン, スプーン 못 읽음). 힌트 1번이면 바로 고침
2. 장음 「う」 누락 계속: きょう를 쿄우/코유로 씀 (→ 쿄-)
3. 동사 부정 과거에 명사용 부정 사용: 飲むではありません (→ 飲みませんでした)
4. 하는 장소 조사: カフェに 食べました (→ で). 다시 쓸 때 では로 고침 (→ で만)
5. 발음: 문장 중간 た를 다(だ)로 적음 (다베마시타 → 타베마시타). 한 번 지적 후 고침
- 잘하게 된 것: 질문 과거형(〜ましたか) 힌트 없이 성공 ← 1회차 약점 극복 / 駅·水·飲 한자 읽기 성공 ← 1회차 약점 극복 / ビ 정확히 읽음 / 새 표현(じゃあ, と, ひとつ·ふたつ)을 바로 응용 / 회화에서 조사 생략을 자연스럽게 함
- 수업 메모: 1회차 숙제는 안 해 옴 (작문만 수업 중 진행, 가타카나 읽기·활용표는 미진행). 여러 문제를 한 번에 받는 걸 선호함

## 숙제 (30분 이내)

2. 활용표 (1회차 숙제 이월): 食べる(たべる, 먹다)와 見る(みる, 보다)를 정중체 4가지로 (〜ます / 〜ました / 〜ません / 〜ませんでした)
3. 편의점 대화 만들기 (한글 독음으로, 정중체)
