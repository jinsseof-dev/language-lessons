> 레벨 체크 + 연습 (약 1시간). 일본어 키보드가 없어서 답은 한글 독음으로 진행.
> 현재 수준: 히라가나 읽기 가능, 가타카나 일부 읽기 가능 → 가타카나 단어에는 독음을 붙이고, 가타카나 연습을 포함할 것.

## 오늘 배운 것

### 핵심 표현 (말투 표시)
- わたしは コーヒーを のみます。(와타시와 코-히-오 노미마스) 나는 커피를 마십니다. [정중체]
- きのう 駅(えき)に 行(い)きました。(키노- 에키니 이키마시타) 어제 역에 갔습니다. [정중체]
- きのう コンビニで 水(みず)を 飲(の)みました。(키노- 콘비니데 미즈오 노미마시타) 어제 편의점에서 물을 마셨습니다. [정중체]
- すみません、駅(えき)は どこですか。(스미마셍, 에키와 도코데스카) 저기요, 역은 어디입니까? [정중체, 여행 필수]
- すみません、水(みず)(を) ください。(스미마셍, 미즈(오) 쿠다사이) 저기요, 물 주세요. [정중체, 회화에서는 を 생략 자연스러움]
- きのう どこに 行(い)きましたか。(키노- 도코니 이키마시타카) 어제 어디에 갔습니까? [정중체]
- いいえ、のみませんでした。ジュースを のみました。(이-에, 노미마셍데시타. 쥬-스오 노미마시타) 아니요, 안 마셨습니다. 주스를 마셨습니다. [정중체, 질문의 말을 반복하지 않는 게 자연스러움]

### 문법 / 문장 구조
- 조사: は(와, 주제) / を(오, ~을/를) / に(니, 가는 목적지 "~에") / で(데, 하는 장소 "~에서")
  - 한국어 "에 / 에서" 구분과 거의 같음: 駅に 行きます / 駅で 待ちます
- 정중체 동사 활용 (스스로 표를 만들어냄)

  | | 行く(이쿠, 가다) | 飲む(노무, 마시다) |
  |---|---|---|
  | ~합니다 | 行きます | 飲みます |
  | ~했습니다 | 行きました | 飲みました |
  | ~하지 않습니다 | 行きません | 飲みません |
  | ~하지 않았습니다 | 行きませんでした | 飲みませんでした |

  - 기본형(行く, 飲む)은 반말(タメ口), ~ます 계열은 정중체
- 질문: 문장 끝에 か → 行きましたか。대답은 はい(하이) / いいえ(이-에)
- 「〇〇は どこですか」(〇〇는 어디입니까?), 「〇〇を ください」(〇〇를 주세요)

### 가타카나 읽기
- 장음 「ー」: 앞 소리를 길게. コーヒー(코-히-), サーバー(사-바-), ケーキ(케-키), データ(데-타)
- 점 두 개(゛)는 탁음: フ→ブ(부), サ→ザ(자), テ→デ(데), ハ→バ(바)
- 작은 글자는 앞 글자와 합쳐 한 소리: カフェ(카페), ファイル(화이루, 파일), フォルダ(호루다, 폴더)
- 영어 "-er" → 「ー」 또는 「ア」: server→サーバー, browser→ブラウザ
- 받침 없음 → 모음 붙음: test→テスト(테스토)
- 오늘 읽은 단어: ホテル, コンビニ, サーバー, データ, テスト, ブラウザ, ジュース, カフェ, ケーキ

### 새로 나온 한자
- 水(みず, 미즈) 물
- 駅(えき, 에키) 역
- 行(い)きます (이키마스) 가다
- 飲(の)みます (노미마스) 마시다

## 약점 (다음 수업 복습 대상)
1. 장음 「ー」·「う」 길게 읽기 누락 ← 1순위: 코-히(→코-히-), 사-바(→사-바-), 케이키(→케-키), 쿄우/키노우(→쿄-/키노-)
2. 시제 맞추기: きのう 문장에서 현재형 사용 (いきます → いきました), 특히 질문 만들 때 (いきますか → いきましたか). 힌트 1번이면 바로 고침
3. 비슷한 가타카나 혼동: バ/ビ (サーバー를 사-비-로 읽음), 처음 보는 가타카나 조합(ブラウザ)
4. 한자를 히라가나로는 알아도 한자로 나오면 못 읽음: 駅(えき)
- 잘하는 것: は/を/に/で 조사 구분 정확, ます 활용 규칙을 스스로 일반화(ません까지 추론), 대답에 문장을 덧붙이는 등 적극적, 힌트 1번이면 대부분 바로 수정
- 수업 메모: 단어 힌트 없이 내 달라고 요청함 (난이도 상향 선호)

## 숙제 (30분 이내)
1. 가타카나 읽기 (한글 독음 + 뜻): ファイル / フォルダ / ユーザー / パスワード / エラー / メニュー
2. 활용표 만들기: 見る(みる, 보다)와 食べる(たべる, 먹다)를 오늘처럼 4가지 정중체로
3. 작문 3문장 (한글 독음으로)
   - 어제 카페에서 케이크를 먹었습니다.
   - 오늘 커피를 마시지 않았습니다.
   - 저기요, 화장실은 어디입니까?
4. 소리 내어 3번 말하기: 「すみません、駅は どこですか。」 (장음 없이 또박또박, 스미마셍 끝은 "셍")
