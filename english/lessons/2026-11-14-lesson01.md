# 영어 수업 기록: 2026-11-14 (1회차)

## 오늘 배운 것
### 핵심 표현
- I have a reservation under Kim. (Kim 이름으로 예약했어요)
- I'll be staying for three nights. (3박 = nights)
- A table for two (people), please.
- Could we get two glasses of water and the menu, please? / Can I get ~, please?
- Medium, please. / I'd like it medium, please.
- bring(가져오다) vs take(가져가다)
- 개발 문서: throw an exception, return null/an error, deprecated(사용 권장 안 함, 지원 중단 예정), will be removed, instead, unless(= if ~ not), in production, should(권장) vs must(필수)

### 문법/문장 구조
- go to + 장소 / for + 시간 / at + 시각 / under + 이름
- a / an / the: 처음 나오는 하나 → a/an(모음 앞 an), 서로 아는 그것 → the
- 주어가 하나 → 동사에 -s (This tool provides / These tools provide)
- be + ~ed (~되다): will be removed, is being tested, was updated

## 약점 (다음 수업 복습 대상)
1. a / an / the 누락 (직접 쓸 때 3회 이상 반복) ← 1순위
2. 전치사 누락/혼동: went cafe, talked to two hours, connect Database, with two people
3. 동사 -s 위치: This tools provide → This tool provides
4. be + ~ed 모양: it is being testing → being tested
5. 철자 실수 잦음 (frined, retuns, loged, funtion, watar, perffered)
6. people에 s 붙임 (peoples)
- 잘하는 것: 빈칸 고르기는 거의 다 맞힘, 문서 독해 이해력 좋음, 원어민식 짧은 답(Medium, please) 자연스러움
