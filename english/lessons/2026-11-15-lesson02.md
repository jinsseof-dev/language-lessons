### 문법/문장 구조
- 처음 나오는 것 → a/an, 이미 말한 것/정해진 그것 → the
  (It was an old building, but the room was clean / returns a new array. The original array... / returns the value for the key)
- old, airport처럼 모음 소리 앞 → an
- 두 동작 연결: This function takes a string and returns a number.
- be + ~ed는 "~되다"일 때만 (내가 하는 동작이면 upgrading 그대로)
- 일반 동사의 부정: does not + 원래 모양 (does not exist / does not return)

## 약점 (다음 수업 복습 대상)
1. a/an/the ← 여전히 1순위
   - 모음 앞 an: a airport (2회 반복), an old building
   - 처음 나오는 것에 the 씀: the old building, the new array
   - 명사 앞 관사 누락: returns new array, If key ~
2. 일반 동사 + be 섞기: is not exists, (1회차 I am agree와 같은 패턴), do backup
3. be + ~ed 과다 사용: before being upgraded (내가 하는 동작인데 "되다" 모양)
4. 주어 하나일 때 동사 -s 누락: and return a value
5. 과거형 누락: talk → talked / 철자: went → want
6. 대문자: 나 = I (i 소문자 3회), 문장 첫 글자, 쉼표 뒤 thanks는 소문자
7. 영어 독해: even if 의미 혼동 (~하더라도)

## 숙제 (30분 이내)
1. 영작 3문장 (a/an/the, does not, 동사 -s 체크)
   - 나는 공항에서 오래된 가방 하나를 샀다. 그 가방은 정말 쌌다. (cheap)

   - 이 함수는 원래 객체를 수정하지 않는다. (modify, original object)
2. 내가 쓰는 라이브러리 문서에서 "does not" 또는 "even if"가 들어간 문장 2개 찾아서 해석
